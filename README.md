# 🐾 Ferreira's Pet Shop — Site + Banco de Dados

Projeto completo de um pet shop: **site institucional e de produtos** em HTML/CSS e **modelagem do banco de dados** nas três etapas (conceitual, lógica e física), com o script SQL.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white) ![SQL](https://img.shields.io/badge/SQL-4479A1?style=flat-square&logo=mysql&logoColor=white)

## 🌐 Site
Páginas: início (`index.html`), produtos, serviços, carrinho e sobre a empresa.

## 🗄️ Banco de dados
- **Modelo conceitual:** `Conceitual ferreiraspetshop.png` (brModelo)
- **Modelo lógico:** tabelas cliente, produtos, itens e vendas (PDFs)
- **Modelo físico:** documentação em `.docx`
- **Script:** `ferreiras_petshop.sql`

## ▶️ Como ver
- Site: abra o `index.html` no navegador.
- Banco: execute `ferreiras_petshop.sql` no MySQL.
